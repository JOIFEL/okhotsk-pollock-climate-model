# Климат и промысел в динамике биомассы североохотоморского минтая (1963–2025)

Этот репозиторий содержит рукопись статьи, воспроизводимые расчёты и сводную базу данных (1963–2025) для анализа вклада климатических факторов (морской лёд, температура, AO, PDO) и промысловой нагрузки (вылов, ОДУ) в межгодовую и междекадную динамику биомассы минтая *Gadus chalcogrammus* в северной части Охотского моря.

## Структура репозитория

- `manuscript/` — рукопись (DOCX + PDF).
- `data/` — итоговая база данных (CSV и Excel) + словарь переменных.
- `scripts/` — скрипты для расчётов и построения рисунков.
- `outputs/figures/` — рисунки (PNG, 300 dpi).
